## Task 118 — one-command dev helper

diagnosis. The build/install/launch loop itself is already exactly
three documented commands (Article 36):

```powershell

.\gradlew.bat installDebug

```

A dedicated wrapper script is deferred until Phase 06 onward changes
what "launch" needs to mean (e.g. clearing app data between manual
test passes) -- adding one now would wrap three lines for no real
benefit yet, matching Article 30's "do not accumulate speculative
tooling" discipline.
